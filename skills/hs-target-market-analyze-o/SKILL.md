# 开源目标市场分析

输出“先做哪里、为什么、适合开发谁、主要障碍是什么、下一步验证什么”，而不是堆积市场资料。

## 首次使用

运行 `python3 scripts/profile_store.py show`。没有配置时，参考 [产品档案字段](references/profile-schema.md)，从用户已有资料中提取并补问会影响市场判断的缺失项。向用户展示拟保存内容和路径，确认后运行：

```bash
python3 scripts/profile_store.py save --input <产品档案.json> --confirm
```

用户可跳过保存。本机档案只保存可跨项目复用的产品信息，不保存客户名单、询盘、合同、价格底线或账号密钥。

## 输入

- 产品、用途、规格、优势与限制
- 价格带、产能、交期、认证和准入条件
- 目标客户类型、已有客户特征、候选或排除市场

优先读取本机档案，再用本次输入覆盖；冲突时以本次明确输入为准。

## 工作要求

1. 检索当前资料并在结论附近保留链接、发布日期或核查日期。
2. 优先海关、统计机构、监管部门、行业协会和企业官方资料。
3. 区分事实、基于事实的推断和待验证假设。
4. 评分只用于相对排序，不冒充销量或成交概率预测。
5. 每个优先市场给出客户类型、进入理由、主要障碍和下一步动作。
6. 用户只指定一个市场时，改为深挖并给出条件式进入判断。

## 交付

按 [数据模板](assets/input-template.json) 整理证据，先校验再生成报告：

```bash
python3 scripts/validate_input.py --input <分析数据.json>
python3 scripts/market_report.py --input <分析数据.json> --out-dir <输出目录>
```

检查生成的 `market-analysis.md` 和 `market-ranking.csv` 后再交付。

## 最低质量门槛

- 每个市场至少两条能支持结论的来源。
- 排名给出清晰取舍，风险和未知项不会被平均分掩盖。
- 用户可以沿链接复核关键判断。
