# 产品档案字段

```json
{
  "product": {
    "name": "",
    "applications": [],
    "core_specs": [],
    "strengths": [],
    "constraints": [],
    "price_band": "",
    "capacity": "",
    "lead_time": "",
    "certifications": []
  },
  "ideal_customers": {
    "types": [],
    "industries": [],
    "order_characteristics": []
  },
  "market_preferences": {
    "candidate_markets": [],
    "excluded_markets": [],
    "risk_constraints": []
  }
}
```

未确认字段保持空值。不要保存客户名单、交易记录、合同、内部成本、最低成交价、账号密码或密钥。
