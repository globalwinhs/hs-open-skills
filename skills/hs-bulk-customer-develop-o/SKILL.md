# 开源批量客户开发

围绕明确产品、市场和客户类型建立可复核、可跟进的名单，重点是质量而不是凑数量。

## 首次使用

运行 `python3 scripts/profile_store.py show`。没有配置时，根据 [开发画像字段](references/profile-schema.md) 提取产品、理想客户和排除条件。向用户展示拟保存内容和路径，确认后运行：

```bash
python3 scripts/profile_store.py save --input <开发画像.json> --confirm
```

用户可跳过保存。画像不保存具体客户、历史询盘、私人联系方式、平台账号或密钥。

## 输入

- 产品、用途、优势、限制与理想订单特征
- 已确定的国家或地区
- 客户类型、渠道、规模、认证要求
- 排除条件、名单数量和需要的联系方式类型

优先读取本机画像，再以本次输入覆盖。市场没有确定时，不擅自替代目标市场分析。

## 开发要求

1. 先定义纳入与排除标准，再搜索公司。
2. 官网或可靠商业页面必须能证明公司身份；搜索摘要不能单独作为依据。
3. 每家公司至少保留一个支持其身份与客户类型的来源。
4. 联系方式必须公开且保留出处；不得猜测、拼接或生成邮箱和手机号。
5. 去除重复公司、错误官网、供应商、竞争对手及明显不符主体。
6. 区分公司匹配、采购信号和联系可达性；优先级不等于已确认采购意向。
7. 数量不足时如实交付已验证名单，不用低质量记录凑数。

## 交付

按 [数据模板](assets/input-template.json) 整理候选客户，运行：

```bash
python3 scripts/validate_input.py --input <客户数据.json>
python3 scripts/lead_batch.py --input <客户数据.json> --out-dir <输出目录>
```

检查 `customer-leads.csv` 和 `batch-summary.md`，重点复核去重记录、A级客户和风险标记。
