```json
{
  "seller_product": {
    "name": "",
    "applications": [],
    "ideal_customer_roles": [],
    "minimum_order_characteristics": []
  },
  "risk_policy": {
    "preferred_payment_terms": [],
    "unacceptable_payment_terms": [],
    "high_risk_signals": [],
    "mandatory_verification_items": []
  },
  "market_focus": {
    "priority_countries": [],
    "restricted_countries": []
  }
}
```

不保存具体客户、询盘、联系人、交易金额、调查结果、账号密码或密钥。法规和制裁状态必须按调查日期重新核验。
